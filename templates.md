## Feature
```
## Summary
A clear and concise description of the feature you would like to see added.

## Problem Statement
Describe the problem this feature solves or why it would be useful.

## Proposed Solution
Explain how you think the feature should work.

## 📋 Additional Details
Include mockups, examples, references, or any additional context that helps explain the request.

## ✅ Acceptance Criteria (optional)
- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3
```
